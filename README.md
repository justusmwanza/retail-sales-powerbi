# Retail Sales Power BI Dashboard

## Project Overview
An end-to-end Power BI dashboard analyzing retail and e-commerce 
sales performance built using Power Query, data modeling, and DAX.

## Tools Used
- Power BI Desktop
- Power Query
- DAX

## Key Features
- Data cleaning and transformation using Power Query
- Star schema data modeling
- DAX measures including YoY and MTD calculations
- Interactive sales performance dashboard
